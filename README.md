# 🎨 Color Detection using OpenCV

A Computer Vision project that detects and identifies colors from an image using Python, OpenCV, and Pandas. By double-clicking on any pixel in the image, the application displays the detected color name along with its RGB values.

---

## 📖 Overview

Color Detection is a simple yet practical Computer Vision application that enables users to identify colors from images interactively. The project uses a predefined dataset of color names and RGB values to find the closest matching color.

---

## ✨ Features

- 🎨 Detect colors from an image
- 🖱️ Double-click to identify any color
- 📊 Display RGB values
- 📝 Show the closest matching color name
- ⚡ Simple and interactive interface

## 🚀 How It Works

1. Load an image using OpenCV.
2. Double-click anywhere on the image.
3. Capture the RGB values of the selected pixel.
4. Compare them with the color dataset.
5. Display the closest matching color name and RGB values.
